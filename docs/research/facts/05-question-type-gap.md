# 出題類型の突合表

最終更新: 2026-09-08
検証方法: `src/data/exam-config.json` の `questionTypes` と `src/exam.ts` の
`TEMPLATE_SOURCE` を突き合わせたもの。数値はコードから再現できる。

検定対策ツールである以上、**本番の出題と乖離していないか**を確認し続ける必要がある。
テンプレートを追加・変更したら、この表を必ず更新すること。

## 公式学習プリントによる裏付け（2026-09-08 追記）

公式の3級学習ツール全9枚・計51問を測定した（`06-official-worksheets.md`）。
**登録年・所在都道府県・所在国・地方を答えさせる設問は0問**だった。
本ツールが現在出している5種類のテンプレートは、すべてこの範囲に属する。

プリントは本試験ではなく、形式も92%が空欄記入であるため、
本試験の類型比率の代用にはできない。しかし主催者自身が3級学習者に
何を問うているかの標本としては、公式例題5問に対し51問と桁違いに大きい。
**下表の「未対応」が、想定より深刻であることを示す独立した証拠**として扱う。

## 物差しの弱さ（先に断っておく）

比較の基準にしている類型比率は、**公式が公開している3級例題5問からの推定**であり、
確度は「推定・根拠弱」。公式は類型別の比率を公表していない。
確度を上げる唯一の手段は公式過去問題集の入手とされている
（`exam-spec.md` §1-4、`../open-questions.md` S4）。

したがってこの表が示すのは「**ズレている方向**」であって、正しい配分の絶対値ではない。

## 突合

| 公式の類型（推定） | 比率 | 対応するテンプレート | 状態 |
| --- | ---: | --- | --- |
| 説明文・空欄補充から遺産名を特定 | 35% | 手書き問題 | 一部対応。遺産固有の知識を問う形で代替 |
| 基礎知識（条約・ユネスコ・登録基準） | 25% | **手書き問題** | **対応済み**。26問の手書きプールで全量を担う |
| 所在国・所在都道府県・地理的位置 | 12% | `place` `region` | 対応済み |
| 関連づけ（共通点をもつ別の遺産・人物・出来事） | 12% | `related` ＋手書き問題 | 生成分は近似のみ（下記）。手書きが本来の形を補う |
| 写真・図版 | 8% | なし | 未対応。画像の権利処理が必要 |
| 登録年・年代 | 5% | `year` | 対応済み |
| 時事（最新の登録・委員会動向） | 3% | なし | 未対応。手書き問題が必要 |

### 実測（200回の模試・4,000問）

| テンプレート | 実測比率 | 対応する公式類型の比率 |
| --- | ---: | ---: |
| 手書き問題 | 65.0% | 基礎知識25% ＋ 遺産固有の知識 |
| `related` | 12.4% | 関連づけ 12% |
| `place` ＋ `region` | 11.7% | 所在地 12% |
| `pickByType` | 5.8% | （対応する類型なし） |
| `year` | 5.1% | 登録年 5% |

手書き問題が大部分を占めたことで、**残る生成分の比率が公式の推定値とほぼ一致**した。

## 是正した乖離

以前は重みをコードに直接書いていた（`year: 0.3` など）。その結果:

| | 旧・手書きの重み | 公式の推定比率 |
| --- | ---: | ---: |
| 登録年 | **30%** | **5%** |

**登録年を6倍出していた。** これを裏付ける独立した根拠が2つある。

- 公式例題5問に登録年を問う問題は1問も出ていない
- 公式の学習ポイントは登録年ではなく「遺産の位置」「世界遺産委員会の開催国」を強調

現在は `TEMPLATE_SOURCE` が各テンプレートを公式の類型に対応づけ、重みは
`exam-config.json` から導出される。推定値が更新されれば出題も自動で追随する。

## 対応づけの根拠

| テンプレート | 対応する類型 | その類型のうち何割を担うか | 根拠 |
| --- | --- | ---: | --- |
| `year` | 登録年・年代 | 100% | そのもの |
| `place` | 所在国・都道府県・地理的位置 | 50% | 1つの類型を `place` と `region` で分担 |
| `region` | 同上 | 50% | 同上 |
| `related` | 関連づけ | 100% | **近似**。下記参照 |
| `pickByType` | 基礎知識 | 20% | **根拠なし**。公式の類型に対応するものがない |

なお手書き問題はこの配分の外側にある。分野（基礎知識／日本／世界の自然／世界の文化）ごとに
先に手書きから取り、残りをテンプレートで埋める。基礎知識は全量が手書き。

### `related` が近似にとどまる理由

公式例題の関連づけは**主題による結びつき**である（ローマ→古都奈良、ローマ→ヴァティカン市国）。
本ツールが持つデータで作れるのは「同じ年に登録された」「同じ地方・同じ国にある」という
**属性の一致**でしかない。形式は似ているが、問うている力は異なる。
本来の関連づけ問題を作るには手書き問題が必要。

### `pickByType` に根拠がないこと

「次のうち、文化遺産として正しいものはどれか」に相当する類型が公式の類型リストにない。
遺産の種別を理解しているかを問うものなので暫定的に基礎知識に分類し、その2割を担うものとした。
**この2割という数字に根拠はない。** 過去問が手に入ったら見直すこと。

## 構造の乖離（未対応）

公式の設問文パターンの筆頭は「**次の文章を読んで、以下の問いに答えなさい。**」であり、
**長文1本に小問が複数ぶら下がる形式**である（`exam-spec.md` §1-4）。
本ツールは独立した一問一答を並べているだけで、この構造を再現していない。

## 実問題を参照するときの線引き

| やること | 可否 |
| --- | --- |
| 実問題を読んで類型を数える | ○ 事実の抽出 |
| 設問文の形式・言い回しを観察して自作の文面に反映する | ○ 形式に著作権は及ばない |
| 難易度感、選択肢の作り方の傾向を把握する | ○ |
| 設問文・選択肢をそのまま、または軽微な改変で問題データに入れる | **× 転載** |
| 過去問・公式プリントの本文をリポジトリに保存する | **×** |

**測るために読むのは問題ない。写して使うのが問題。**
