### 1-4. 出題傾向の類型

公式が公開している**3級例題5問**（[3級ページ](https://www.sekaken.jp/each_grade/ex_class3/)）の形式のみが一次情報。類型別比率は公式非公表のため**すべて推定・根拠弱**。

| 類型 | 推定比率 | 根拠 |
|---|---|---|
| 説明文・空欄補充から遺産名／語句を特定 | 35% | 3級例題5問中2問がこの形式。区分「基礎知識」「世界の文化遺産」で多用と推定 |
| 世界遺産条約・ユネスコ・登録基準など基礎知識 | 25% | 公式比率「基礎知識25%」に対応 |
| 所在国・所在都道府県・地理的位置 | 12% | 公式学習ポイント「遺産の位置なども覚えておきましょう」 |
| 関連づけ（共通点をもつ別の遺産／人物・出来事） | 12% | 3級例題5問中2問がこの形式（ローマ→古都奈良、ローマ→ヴァティカン市国） |
| 写真・図版を見て答える | 8% | 3級例題5問中2問が写真・国旗を伴う |
| 登録年・年代 | 5% | 3級例題には出現せず。公式学習ポイントは登録年より「位置」「委員会開催国」を強調 |
| 時事（最新の登録・世界遺産委員会） | 3% | 公式学習ポイント「世界遺産委員会の開催国や、審議された日本の遺産も重要です」 |

- **登録基準(i)〜(x)を直接問う設問**は3級例題に出現せず、公式の学習ポイントでも「日本の遺産については、登録基準も覚えるようにしてください」は**2級**の記述。3級では低比率と推定。
- 参考: 4級では「次の3つの説明文から推測される世界遺産は何でしょうか」型、2級では「次の3つの説明文から推察される〜はどれか」型が公式例題にある。

#### 設問文の定型表現（3級・確定）

- 導入: 「次の文章を読んで、以下の問いに答えなさい。」（長文1本に小問が複数ぶら下がる形式）
- 語尾: **すべて「〜として、正しいものはどれか。」**（常体）
- 具体例（公式例題より、形式のみ）: 「〜の正式名称として、正しいものはどれか。」／「文中の空欄にあてはまる世界遺産の名称として、正しいものはどれか。」／「この写真の建物の名称として、正しいものはどれか。」
- 選択肢は「1.〜4.」の4肢、正解1つ。
- **重要**: 4級のみ「〜でしょうか。」の敬体を用いる。**3級の自動生成では敬体を使わないこと。**
- 否定形「〜として、正しくないものはどれか。」は2級・4級の公式例題で確認。3級での出現は**推定**。

### 2-4. 画像（優先度低）

- **Wikimedia Commons の帰属表示（[Commons:Credit line](https://commons.wikimedia.org/wiki/Commons:Credit_line)）**
  - CC BY / CC BY-SA: **著作者名・作品タイトル（あれば）・ライセンス名とそのURI**が必須。実務上の最小形は `John Doe / CC BY-SA 3.0`、丁寧な形は `© John Doe / Wikimedia Commons / CC BY-SA 3.0`。改変した場合はその旨も明記。
