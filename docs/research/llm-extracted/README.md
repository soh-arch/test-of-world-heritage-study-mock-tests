# LLM-extracted — 未検証の抽出情報

> **警告: ここにある数値・記述を、一次情報での裏取りなしに実装へ取り込んではならない。**

これらは調査エージェント（LLM）がWeb検索の結果から抽出・整理したレポートである。
調査環境のネットワーク制限（`../facts/01-environment.md`）により、
`sekaken.jp` や `whc.unesco.org` といった一次情報源を**直接閲覧できていない**。
したがって、レポート内で「公式情報」と分類されている項目も、実際には
**公式情報を引用する二次情報サイトの検索スニペット経由**の間接情報である。

| ファイル | 内容 | 主な未確定事項 |

## 各レポートの確度について

レポート内の各項目には「確度（高／中／低）」が付されている。この表記を信用し、
**確度「低」の数値は暫定値としてのみ扱う**こと。特に次の2点は実装の根幹に関わる。

- **分野別の出題比率**: 公式が%を公表しているか自体が不明。
  実装では設定ファイル（`exam-config.json`）に外出しし、ハードコードしないこと。
- **UNESCOデータの再配布条件**: 「書面許諾が必要」という理解が正しければ、
  UNESCO由来の生データをリポジトリに含めて公開することはできない。
  この判断がデータ設計を左右するため、原文の直接確認が必須。

## 検証の進め方

`../prompts/local-research-agent.md` を、ネットワーク制限のない環境の調査エージェントに渡す。
返ってきた結果で裏が取れた項目は `../facts/` に昇格させ、`../open-questions.md` から消す。
