# ローカル調査エージェント向け依頼プロンプト

ネットワーク制限のない環境で実行する調査エージェントに、以下をそのまま渡す。
返ってきた成果物は、裏取り済みの事実として `docs/research/facts/` に配置し、
`docs/research/open-questions.md` の該当行を消す。

---

## 調査依頼：世界遺産検定3級 模試ツール開発のための一次情報確認

あなたは調査エージェントです。日本語で調査し、指定された成果物を出力してください。
別環境の調査で概要は掴めていますが、**ネットワーク制限により公式サイトを直接閲覧できなかった**ため、
以下はすべて「二次情報・確度低〜中」の状態です。**公式サイトの直接閲覧による確定**が目的です。

### 全体ルール

- 一次情報（世界遺産検定公式 sekaken.jp / NPO法人 世界遺産アカデミー / UNESCO公式 / 文化庁・外務省）を最優先。
- すべての事実に **出典URL・閲覧日・確度（確定／推定／不明）** を付す。
- **推測で埋めないこと。** 確認できなければ「不明」と明記する。
- **著作物の本文をコピーしないこと。** 必要なのは事実（数値・名称・年・分類）のみ。
  公式テキストや過去問の文章・設問文をそのまま書き写さない。

---

### 第1部：試験仕様の確定（最優先）

公式サイト（https://www.sekaken.jp/）を直接閲覧して確定させてください。

#### 1-1. 3級の仕様

以下を表で確定。既存の二次情報値を括弧内に示すので、正誤を判定してください。

- 出題数（既存情報：60問）
- 試験時間（既存情報：50分）
- 満点と合格ライン（既存情報：100点満点／60点以上）
- **配点は均等か、問題ごとに異なるか**（既存情報：問題により異なる＝要確定）
- 出題形式（既存情報：四肢択一マークシート）／記述問題の有無
- 受験資格、受験料（公開会場／CBT それぞれ。既存情報が4,900円説と5,400円説で割れている）
- 年間の実施回数・時期、公開会場試験とCBTの違い（出題内容は同一か）
- 直近数年の認定率（合格率）

#### 1-2.【最重要】分野別の出題構成比

**これが出題アルゴリズムの根幹**です。公式が示す出題範囲の区分と、その割合を確定してください。

- 区分は「基礎知識／日本の遺産／世界の遺産（自然）／世界の遺産（文化）／その他」で正しいか
- **各区分が全体の何%（または何問）を占めるか**
- 公式が%を公表していない場合は、その事実を明記した上で、
  公式テキストの章立てページ配分や、複数の学習サイトの記述から**推定値と根拠**を示す

#### 1-3.【最重要】出題対象となる遺産の範囲

- 日本の世界遺産：**現時点で何件登録されているか**（2024年「佐渡島の金山」以降の追加を含めた最新の総数）。全件が3級の対象か。
- 世界の遺産：**「代表的な100件」とは具体的にどの100件か。**
  公式テキスト『きほんを学ぶ世界遺産100〈第5版〉』が扱う遺産の**名称リスト**を特定してください
  （目次・書籍紹介ページ・書評等から。本文の書き写しは不要、遺産名の一覧のみ）。
  特定できない場合は「不明」とし、代替として学習サイト等で頻出とされる遺産名リストを出典付きで提示。
- 4級・2級の対象件数（将来の級追加のため参考程度に）

#### 1-4. 出題傾向の類型

3級の問題が**どういう問われ方**をするかを類型化してください（設問文の丸写しは不要、形式の説明のみ）。

- 例：「登録年を問う」「所在国/都道府県を問う」「登録基準を問う」「説明文から遺産を特定させる」
  「写真を見て答えさせる」「時事（最新の登録）を問う」「世界遺産条約の基礎知識を問う」
- **各類型がおよそ何割か**の推定
- 3級の設問文が**どういう日本語の言い回し**で書かれるか（例：「〜として正しいものはどれか」などの定型表現の傾向）。
  → 自動生成する問題文を本番に近づけるために必要。

#### 1-5. 商標・名称使用

- 「世界遺産検定」の商標登録状況（既存情報：登録第5289275号。J-PlatPatで実際に確認すること）
- 権利者、指定役務、現在有効か
- **非公式の個人向け学習ツールで「世界遺産検定3級 対策」等と表示する際の適切な表記**
  （「非公式」「公式とは無関係」等のディスクレーマー文言の実例を、他の非公式検定対策サイトから調べる）

### 第2部：データソースの確定

#### 2-1. Wikidata（最重要・実クエリを実行すること）

Wikidata Query Service（https://query.wikidata.org/）で**実際にSPARQLを実行**し、結果を報告してください。

確認したいこと：

- 世界遺産（Q9259 / P1435 heritage designation）を全件取得できるか
- **日本語ラベル（rdfs:label @ja）がどれくらい揃っているか**（全件中何%に日本語名があるか）
- 取得できるプロパティ：登録年（P580 start time など）、所在国（P17）、登録基準（P2614 World Heritage criteria）、
  WHS ID（P757）、所在地/行政区画（P131）、座標（P625）、画像（P18）、Wikipedia言語版数（sitelinks数）
- **日本の世界遺産を全件、日本語名付きで取得するクエリ**を作成し、実行結果をそのまま添付
- ライセンスが CC0 であることの公式ページでの確認（帰属表示が不要であることの裏取り）

#### 2-2. 日本の世界遺産の公式な日本語名称

- 文化庁・外務省・各遺産の公式サイトで、**正式な日本語表記**を確認
  （例：「法隆寺地域の仏教建造物」「紀伊山地の霊場と参詣道」など、揺れやすいもの）
- 各遺産の **所在都道府県**（複数県にまたがるものはすべて列挙）
- 各遺産の **登録年・種別（文化/自然/複合）・登録基準（i〜x）**

#### 2-3. UNESCO公式データの再利用条件（再確認）

- https://whc.unesco.org/en/faq/126 および https://whc.unesco.org/en/licenses/ を直接閲覧し、
  **再配布に書面許諾が必要という理解が正しいか**を原文引用で確認
- 明示的にオープンライセンスで提供されているデータセットが別途存在しないか

#### 2-4. 画像（第2版以降の検討材料、優先度低）

- Wikimedia Commons で日本の世界遺産の画像を使う場合の、実務上の帰属表示のやり方
- パブリックドメイン／CC0 の画像だけに絞れるか

### 成果物（4ファイル）

#### ① `exam-spec.md`

第1部の調査結果。すべて出典URL・閲覧日・確度付き。
末尾に「確認できなかった項目」を明記すること。

#### ② `exam-config.json`

出題アルゴリズムに直接投入する設定ファイル。以下の形式で。

```json
{
  "grade": "3",
  "source_verified_at": "2026-XX-XX",
  "total_questions": 60,
  "time_limit_minutes": 50,
  "total_points": 100,
  "pass_score": 60,
  "scoring": "uniform | weighted",
  "scoring_note": "",
  "categories": [
    { "key": "basic",           "label": "基礎知識",         "ratio": 0.00, "confidence": "確定|推定|不明", "source": "URL" },
    { "key": "japan",           "label": "日本の遺産",       "ratio": 0.00, "confidence": "", "source": "" },
    { "key": "world_natural",   "label": "世界の遺産(自然)", "ratio": 0.00, "confidence": "", "source": "" },
    { "key": "world_cultural",  "label": "世界の遺産(文化)", "ratio": 0.00, "confidence": "", "source": "" }
  ],
  "question_types": [
    { "key": "year", "label": "登録年を問う", "estimated_ratio": 0.00, "confidence": "" }
  ],
  "scope": {
    "japan_sites_count": 0,
    "japan_all_included": true,
    "world_sites_count": 100,
    "world_sites_list_identified": true
  },
  "phrasing_patterns": [
    "〜として正しいものはどれか。"
  ]
}
```

#### ③ `japan-sites.json`

日本の世界遺産**全件**。これが第1版のデータ基盤になるので、**正確性を最優先**。

```json
[
  {
    "id": "jp-horyuji",
    "name_ja": "法隆寺地域の仏教建造物",
    "name_en": "Buddhist Monuments in the Horyu-ji Area",
    "prefectures": ["奈良県"],
    "region_jp": "近畿",
    "registration_year": 1993,
    "type": "cultural",
    "criteria": [1, 2, 4, 6],
    "is_transboundary": false,
    "in_danger": false,
    "source": "URL",
    "confidence": "確定"
  }
]
```

- `criteria` は i〜x を 1〜10 の数値で
- `type` は `cultural` / `natural` / `mixed`
- **登録年と登録基準は必ず一次情報で裏取りすること**（ここの誤りが全問題の誤りになる）

#### ④ `world-sites-candidates.json`

3級の対象となる「世界の代表的な100件」の候補リスト。
`japan-sites.json` と同じスキーマ（`prefectures`/`region_jp` の代わりに `country_ja` / `unesco_region`）。

- 100件が特定できた場合はその100件
- 特定できない場合は、Wikidata の sitelinks 数など**機械的な知名度指標**で上位を抽出し、
  その抽出方法と指標値を併記すること
