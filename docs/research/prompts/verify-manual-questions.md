# 手書き問題の一次確認プロンプト

`data/manual-questions.json` の問題を、ネットワーク制限のない環境で一次情報にあたって確認するための依頼。
このリポジトリのサブエージェントによる検証は、外部サイトへ到達できないため
**検索スニペットと手持ちの確認済みデータに限られる**（`facts/01-environment.md`）。
最終的な確度はこの依頼で上げる。

---

## 依頼：世界遺産検定3級 模試ツールの手書き問題の事実確認

`data/manual-questions.json` に入っている4択問題を、1問ずつ一次情報で確認してください。
**批判的に見てください。承認するのが仕事ではありません。**

### 各問について確認すること

1. **`answerKey` が指す選択肢は本当に正しいか。**
2. **誤答の選択肢に、実は正解と言えるものが混ざっていないか。** 最も見落とされやすい欠陥です。
3. **`explanation` に事実誤りがないか。**
4. `siteId` が指す遺産と設問の対象が一致しているか。
5. 3級のレベルとして妥当か。

### 優先順位

| 優先 | 対象 | 理由 |
| --- | --- | --- |
| 高 | `verified: false` の問題 | 作成者（Claude）の知識だけが根拠で、出典がない |
| 中 | `volatile: true` の問題 | 件数など、時間が経つと答えが変わる |
| 低 | `source` が「3級学習ツール◯ 解答」の問題 | 主催者自身の解答面が根拠。転記ミスの確認のみ |

### 一次情報として使ってよいもの

- 世界遺産検定公式サイト `sekaken.jp`（各級の説明、例題）
- 世界遺産ナビ pamon `pamon.sekaken.jp`（**事実データの参照のみ。解説文は使わない**）
- UNESCO `whc.unesco.org`
- 文化庁、外務省、各遺産の公式サイト
- 公式が無償配布している学習ツールPDF

### やってはいけないこと

- 公式テキストや過去問の**設問文・選択肢をそのまま持ち込むこと**
- pamon やUNESCOの**解説文を問題データに転記すること**

事実（人物名、年、地名、用語）の確認に使うのは問題ありません。

### 出力

各問について次を返してください。

```json
{
  "id": "問題のid",
  "verdict": "confirmed | wrong | uncertain",
  "source": "確認した一次情報のURL",
  "accessed": "閲覧日",
  "issue": "問題があればその内容",
  "correction": "修正案"
}
```

`confirmed` としたものは `verified: true` に、`source` に確認したURLを入れて反映します。
**確認できなかったものは `uncertain` にしてください。推測で `confirmed` にしないこと。**

### 特に見てほしい論点

- 世界遺産委員会の委員国の任期（公式学習ツールは「6年、ただし4年で交代することが望ましい」としている）
- 「負の遺産」に公式の定義があるか。ないなら断定してよいか
- 登録抹消された遺産の件数と内訳（現時点で何件か）
- 日本の世界遺産の件数と、3級の出題範囲の基準日
  （テキスト第5版は26件時点。『飛鳥・藤原の宮都』が出題対象かは未確認＝`open-questions.md` D2）
- 選択肢に使った造語（「原初性」「十全性」「包括性」など）が、
  実は別の意味をもつ専門用語として使われていないか
