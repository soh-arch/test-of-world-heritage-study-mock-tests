# Research

世界遺産検定3級 模擬試験ツールの調査記録。

## ディレクトリの区分

このディレクトリは **検証の度合いによって明確に分離** されている。混同すると、
未検証の推定値がそのまま実装の前提として固定されてしまうため、区分を厳守すること。

| ディレクトリ | 内容 | 実装で使ってよいか |
| --- | --- | --- |
| `facts/` | **検証済みの事実**。コマンド実行結果、実測値、実際に取得したファイルの中身など、このリポジトリ内で再現・追試できるもののみ。 | そのまま使ってよい |
| `llm-extracted/` | **LLMエージェントが抽出した未検証の情報**。Web検索スニペット由来の二次情報を含む。数値の多くは確度「中」以下。 | **そのまま使ってはならない。** 一次情報での裏取り後に `facts/` へ昇格させる |
| `prompts/` | 調査エージェントに渡した/渡す依頼プロンプト。 | — |
| `open-questions.md` | 未確認事項のチェックリスト。裏取りが済んだ項目をここから消していく。 | — |

## 昇格のルール

`llm-extracted/` の情報を `facts/` に移すには、次のいずれかを満たすこと。

1. 一次情報（公式サイト・公的機関）を**直接閲覧**して確認し、出典URLと閲覧日を記録した
2. このリポジトリ内で**再現可能な手順**（スクリプト・コマンド）によって検証した

いずれの場合も、`facts/` に置く記述には**根拠と検証方法**を併記する。

## 経緯

初回の調査は、リモート環境のネットワークegress制限により一次情報へ到達できなかった
（詳細は `facts/01-environment.md`）。その成果は `llm-extracted/` にある。

その後、ネットワーク制限のない環境の調査エージェントに
`prompts/local-research-agent.md` を渡して再調査し、**2026-09-09 に一次情報での確定を得た**。
その成果が `facts/exam-spec.md` と `facts/data/` である。

主要な数値（60問50分／分野比率／日本27件／受検料／商標）は確定した。
残る未確定項目は `open-questions.md` を参照。
