# 世界遺産検定3級 模擬試験（非公式）

日本の世界遺産27件から、毎回異なる模擬試験を組み立てる静的Webツール。
問題はテンプレートと確定済みの事実データから生成される。

> 「世界遺産検定」は登録商標（登録第5289275号）です。本ツールは非公式の学習ツールであり、
> NPO法人世界遺産アカデミー、株式会社マイナビおよび世界遺産検定事務局の承認・推奨・監修を
> 受けたものではありません。

## 現在の範囲

- 出題範囲は**日本の全27件＋世界の主要遺産83件**。20問・一括採点・分野別内訳・誤答の復習。
- 問題テンプレートは5種類。登録年 / 所在地（都道府県・国）/ 地方・地域 / 関連づけ / 種別による選択。
- テンプレートの配分は `exam-config.json` の出題類型から導出する。
  乖離の状況は `docs/research/facts/05-question-type-gap.md` に記録している。
- 分野の配分は公式比率に従う。日本の遺産9問 / 世界の自然遺産3問 / 世界の文化遺産8問。

試験仕様（60問50分・分野比率25/30/10/30/5）は公式サイトで確認済みで
`docs/research/facts/data/exam-config.json` にある。20問なのは、
**基礎知識25%と「その他」5%が手書き問題を必要とし、まだ作れないため**。
作れる3分野（合計70%）の比率を保ったまま縮尺しているので、分野の重みは本番と同じ。

世界の遺産は、3級の範囲とされる100件のうち公式資料から再構成できた83件
（研究データ84件から、日本側と重複するル・コルビュジエを除いたもの）。
うち大半は掲載ページからの推定であり、残り約16件は未特定
（`docs/research/open-questions.md` D1）。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # 出題エンジンのテスト
npm run check    # データ生成 + 型チェック + テスト
npm run build    # 本番ビルド
```

`main` にあたるブランチへの push で GitHub Actions が検査してPagesへ配信する。

## 構成

```
docs/research/          調査記録。facts/ が検証済み、llm-extracted/ が未検証
scripts/build-data.mjs  調査データ → アプリ用データへの正規化
src/generator.ts        問題テンプレート、誤答生成、バリデーション
src/exam.ts             模試の組み立てと採点
src/main.ts             画面
```

### データの流れ

```
docs/research/facts/data/*.json  ← 一次情報で確定した調査データ（手で編集しない）
              │  npm run build:data
              ▼
src/data/*.json                  ← アプリが読む正規化済みデータ（生成物）
```

正規化で `region_jp` の複合文字列を都道府県から導出した配列に置き換えている。
CI は再生成して差分が出ないことを確認する。

## 設計上の約束

- **正誤判定は必ず `id` で行う。** 遺産名にはダッシュ記号が3種類混在しており、
  表示文字列の比較は当てにならない。
- **誤答選択肢は必ず実データから引く。** 年なら別の遺産の実際の登録年、
  都道府県なら同じ地方の別の県。捏造しない。
- **生成した問題は使う前に検証する。** 選択肢の重複、正解と同値の誤答、
  答えが透ける文字数の偏りを弾く（`validate`）。
- **1回の模試で同じ遺産は1問まで。** 別の問題のヒントになるため。
- **同じ設問文は1回の模試で1問まで。** 種別を問う設問は3通りしかなく、
  放っておくと同じ文面が並ぶ。
- **越境遺産に所在地を問わない。** ル・コルビュジエの建築作品は日本データ上
  「東京都」だけを持つが、遺産全体が関東にあるわけではない。
- **出題比率などの値はコードに埋め込まない。** 公式が非公表の項目は推定値であり、
  `exam-config.json` の差し替えで変えられる状態に保つ。テンプレートの重みも同様で、
  以前ここを手書きしていたために登録年を本番の6倍出していた。
- **所在地を問えるのは、場所が1つに定まる遺産だけ。** 越境遺産（ル・コルビュジエ）や
  複数地方にまたがる遺産（明治日本の産業革命遺産）は、所在地・関連づけの対象から外す。

## ライセンスと出典

- 遺産の事実データ（名称・登録年・所在地・登録基準）は公式情報で照合した事実のみ。
  解説文などの著作物は一切利用していない。
- UNESCO の公式データは再配布に書面許諾が必要なため、リポジトリに含めていない。
  詳細は `docs/research/facts/exam-spec.md` §2-3。
